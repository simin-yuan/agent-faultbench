# Public pre-registration — v0.1 baseline

Pushed **before** the runs it governs. Repository: <https://github.com/simin-yuan/agent-faultbench>.

Date: 2026-11-10. This file, the run, and the results are three separate commits, in
that order. The expected values below come from measurements already recorded privately;
they are restated here so that this public run stands on its own, and it will be judged
against them, not against the run.

| Framework | Rows | Variants | Runs | Total |
|---|---|---|---|---|
| NVIDIA NeMo Agent Toolkit 1.9.0 | 2 (`tool_calling_agent`, `react_agent` + native tool calling) | 4 | 3 | 24 |

Variants: `chat-length`, `chat-drop`, `responses-incomplete`, `responses-drop`.

## How a cell is judged

Four fields must match, on all three runs: **verdict, lines, bytes, sha256**. A cell whose
three runs disagree is `unstable` and is neither pass nor fail.

States: `executed`, `not-executed`, `not-measurable`, `error`. `not-measurable` means the
client never requested the wire endpoint that variant needs; such a cell is excluded from
the denominator and is never counted as a pass.

A `not-executed` cell also carries a BT label, and each label needs evidence:

- `blocked-by-end-signal` — the client checked that the reply had finished;
- `blocked-by-parse` — a parser refused the payload;
- `unknown` — the record cannot tell the two apart. **No evidence, no label.**

## Falsifier

If this public run disagrees with the private measurements on any cell, the baseline is
**not confirmed**: the README is marked as such and the discrepancy is investigated
before anything else is published about it.

## What is deliberately absent

The two frameworks whose upstream reports are newer than seven days are **not** in this
release. Their results and pre-registrations are not in this repository yet. Nothing here
names them, and nothing here hints at how many there are.
